# Newsletter

## Zasada naczelna

**Newsletter tworzy człowiek. Ty wspierasz, nie zastępujesz.** To najprywatniejszy kanał: trafia
do skrzynki klientki, nie do feedu, i fałszywy ton czuć tu od razu.

Ty możesz: zaproponować koncepcję (typ, temat, kąt), napisać trudniejszy fragment (jak działa
składnik), ułożyć FAQ, dopracować temat maila i preheader, sprawdzić słowa i prawo, podsunąć
inne zamknięcie. Nie decydujesz o temacie, głównej historii i tonie całości.

Raz w miesiącu, **jeden temat przewodni**, zakorzeniony w tym, co się dzieje (sezon, premiera,
kampania). Pisany jak list, z podpisem człowieka.

## Brief

Zanim zaczniesz, zapytaj o typ i temat, jeśli ich nie dostałaś:

```
TYP: A / B / C
TEMAT:
KOSMETYK/I:
KONTEKST: (premiera, sezon, akcja?)
CEL: (sprzedaż, ogłoszenie, edukacja, relacja)
CO JUŻ JEST: (hasło, pomysł na wstęp, cokolwiek)
```

## Trzy typy

**A. O kosmetyku** (premiera, powrót bestsellera, sezon). 200-350 słów.
1. Nagłówek-teza: sytuacja albo problem ("Lato to nie tylko słońce, ale też pot i dyskomfort.").
2. Jak kosmetyk działa, z mechanizmem.
3. Kosmetyk: nazwa, krótki opis, przycisk.
4. Opcjonalnie zestaw, naturalnie, nie nachalnie.
5. FAQ 2-3 pytania **w treści maila** (to nie jest blogowy JSON).

**B. Akcja / program** (program lojalnościowy, konkurs, zmiana). 100-180 słów.
1. Nagłówek z emocją.
2. Krótki akapit: czym to jest, dlaczego teraz.
3. Lista: co konkretnie dostaje klientka.
4. Jeden przycisk, jeden cel.
5. Opcjonalnie zdanie o relacji ("Bo bez Was nie byłoby nas.").

**C. Edukacyjny / sezonowy** (porady, odpowiedzi na częste pytania). 180-280 słów.
1. Problem albo pytanie, które czytelniczka zna ze swojego życia.
2. 2-4 akapity lub punkty z konkretnymi poradami.
3. Opcjonalnie kosmetyk, jeśli naturalnie pasuje.
4. Zamknięcie.

## Stałe elementy

- **Temat maila:** do 50 znaków, konkretny, bez clickbaitu, najwyżej jedna emotka.
- **Preheader:** jedno zdanie, rozwija temat, nie powtarza go.
- Logo na górze, stopka z linkiem do sklepu, wypisaniem i danymi firmy.

## Ton kanału

- Do jednej osoby: "Ty", nie "drogie klientki", nie "Państwo".
- Ciepło, ale nie infantylnie (nie: "To naprawdę miłe, że jesteś z nami").
- Jeden konkretny fakt o kosmetyku, nie pięć przymiotników.
- Jeden przycisk w typie A i B.
- Opinie klientek wklejamy bez retuszu (i bez obietnic leczenia, `compliance.md`).

Zamknięcia, które brzmią jak my: "Bo bez Was nie byłoby nas. 💚", "Natura. To proste."
Zamknięcia, których unikamy: "Mamy nadzieję, że będziesz zadowolona z naszej oferty",
"Zapraszamy do zapoznania się z naszymi produktami", "Życzymy udanych zakupów!"

## Checklista

- [ ] Jeden temat przewodni
- [ ] Temat maila do 50 znaków, preheader go rozwija
- [ ] Jeden przycisk (A, B)
- [ ] Nazwy kosmetyków i ceny sprawdzone
- [ ] "Kosmetyk", nie "produkt"; zero myślników
- [ ] Zamknięcie brzmi jak my, nie jak korporacja
- [ ] Stopka kompletna
